# Ecosystem documentation authority

The cross-product execution authority is maintained in the Integrity repository:

- `integrity-core/docs/ecosystem/INTEGRITY_ECOSYSTEM_PLAN.md` — execution outcomes and gates;
- `integrity-core/docs/ecosystem/ECOSYSTEM.md` — product and authority boundaries;
- `integrity-core/docs/ecosystem/DATA.md` — data, retention, purge, and evidence boundary;
- `integrity-core/docs/ecosystem/STATUS.md` — current open gaps;
- `integrity-core/docs/ecosystem/ADR-0001-six-function-test.md` — architecture scope test.

Shield-specific implementation, policy, and operational documents remain authoritative only for Shield internals. They must not redefine cross-product identity, receipt, pack, evidence, or product boundaries. Historical and superseded plans belong in `docs/archive/`.
