# Network Shield recovery paths

Management and recovery zones are protected configuration requirements. They must remain
reachable independently of Hermes, Cortex, DNS policy, endpoint containment, and network
adapters.

Recovery requires a local operator with network-admin authority, a fresh authoritative identity,
an exact intent-bound approval, and an acknowledged restore operation. If the target or adapter
state is uncertain, do not guess or issue a broad reset; use the provider's documented recovery
procedure and preserve the local audit trail.
